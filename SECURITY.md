# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately, not in public issues:

- Use [GitHub private vulnerability reporting](https://github.com/seawise-io/seawise-client/security/advisories/new), or
- Email support@seawise.io with "Security" in the subject.

Include the client version (shown in the web UI footer), steps to reproduce and the impact you expect. We aim to reply within 3 business days.

## Supported Versions

Security fixes go into the latest release. Update with `docker pull ghcr.io/seawise-io/seawise-client:latest`.
